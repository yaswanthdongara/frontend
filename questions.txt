1) How does React handle events consistently across different browsers?
A) Through its Synthetic Event System.

2) How can you prevent default behaviors, like a browser refresh in React?
A) By calling the preventDefault() method.

3) How does React differ from standard HTML in naming event attributes?
A) React uses camelCase event names like onClick and onSubmit.

4) In which version of React were hooks introduced, allowing state to be used in functional components?
A) React 16.8

5) What does state represent in a React component?
A) Dynamic data that triggers re-renders when changed.

6) What are the three stages of the rendering process in React?
A) Trigger, render, and commit.

7) Which technology does React use to perfect the render stage by efficiently calculating changes?
A) Virtual DOM

8) What happens during the commit stage in React's rendering process?
A) React applies changes from the virtual DOM to the real DOM.
